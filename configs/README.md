# Configuration scope

`icassp2027.yaml` is the only configuration consumed by the focused paper
entry points.

The older `default.yaml`, `proxy.yaml`, `pretrain_unet.yaml`, and
`finetune_unet.yaml` files are retained solely to inspect historical U-Net and
proxy checkpoints. They describe a different front end and epoch-based budgets.
Do not use them to produce or label ICASSP results.
